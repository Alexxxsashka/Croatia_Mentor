# Спецификация: Неразрушающий редизайн Croatia Mentor (Orange/White Edition)

## Задача

Как пользователь платформы Croatia Mentor (украинский релокант, экспат или международный студент), я хочу иметь возможность переключить интерфейс в яркую, современную, светлую оранжево-белую тему (Vibrant Orange & White), чтобы комфортно учить хорватский язык в светлое время суток, сохраняя свой полный прогресс, XP, историю уроков и все существующие функции платформы.

## Решение

Внедрение альтернативной визуальной системы **Vibrant Orange & White** рядом с существующей тёмной темой **Dark Editorial**. Все элементы бэкенда, база данных PostgreSQL (Prisma), авторизация (NextAuth), AI-чат (GenAI), TTS и учебные модули остаются 100% нетронутыми. В приложение добавляется клиентский контекст управления темой (`ThemeProvider` / `ThemeSwitcher`), а все компоненты адаптируются с помощью токенов CSS и адаптивных Tailwind классов.

## Решения по реализации

1. **CSS Design Tokens (`src/app/globals.css`):**  
   Определение переменных для двух режимов: базовой тёмной темы (`:root` / `[data-theme="dark"]`) и оранжево-белой темы (`[data-theme="orange-white"]`).
2. **Layout Theme Provider & Switcher (`src/components/theme/`):**  
   Клиентский провайдер темы на React Context + localStorage. Добавление аккуратного переключателя темы в Navigation Header.
3. **Impeccable UI Crafting:**  
   Применение принципов Impeccable для создания динамических оранжево-белых градиентов, микро-анимаций (Hover, Active, Focus state) и высокой контрастности.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `theme-provider` | Состоянием выбранной темы (`dark` / `orange-white`) | `useTheme()`, `setTheme()`, атрибут `data-theme` на `<html>` | Логику работы с localStorage/cookies |
| `theme-switcher` | Кнопкой переключателя UI | Компонент `<ThemeSwitcher />` | Анимацию иконок (солнце/луна) |
| `ui-components` | Оформлением интерфейса | Реактивные карточки, кнопки, прогресс-бары | Применение CSS-переменных темы |
